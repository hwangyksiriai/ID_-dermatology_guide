# 페이스코드 — 보류(홀딩) 중

페이스코드 캠페인 진행이 홀딩되어, 운영 페이지(`/index.html`)에서 페이스코드 내용을 빼고 이 폴더에 보관합니다.
이 폴더는 `.vercelignore`로 배포에서 제외됩니다.

## 들어있는 것
- `index.html` — 휴니드 / 페이스코드 **두 시술 선택형** 가이드 전체 (보류 직전 버전)
  - 시술 선택 카드 → 선택한 시술 가이드만 아래에서 올라오는 구조
  - 페이스코드 제공 시술(30~150만원 상당, 5단계 진행), 레퍼런스 4종, DO 항목
  - 페이스코드 선택 시 배너가 `facecode.png`로 교체
  - `?p=hunide` / `?p=facecode` 링크 지원
- `facecode.png` — 페이스코드 배너 이미지
- `hero.jpg` — 휴니드 배너 (이 폴더에서 바로 열어볼 수 있도록 복사본)

## 다시 진행할 때
1. 이 폴더의 `index.html`을 루트 `index.html`과 비교해, 보류 이후 루트에 생긴 변경(문구 수정 등)을 반영합니다.
2. 반영한 `index.html`과 `facecode.png`를 루트로 옮깁니다.
3. 구글시트 연동(`apps-script.gs`)은 지원시술 컬럼을 그대로 쓰므로 수정할 필요 없습니다.
